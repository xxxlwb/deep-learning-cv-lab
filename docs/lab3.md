# 实验 3：Transformer 复现与优化

课程：《深度学习与计算机视觉》
作答时间：10-29 15:49 至 11-19 23:59
数据目录：`data/cifar10/`

## 实验内容

1. **ViT 图像分类基线**：查阅并阅读相关资料和论文，使用 PyTorch 等框架搭建 Vision Transformer（ViT），完成 CIFAR-10 图像分类任务。训练时使用课程提供的 CIFAR10_imbalanced 数据集，测试时使用 CIFAR10_balance 数据集。
2. **类别不均衡处理**：针对训练集存在的类别不均衡问题，至少尝试一种处理方法，并解释其基本原理、具体实施方式及对分类结果的影响。
3. **ViT 轻量化**：在分类性能无明显下降的前提下，至少尝试 2 种 ViT 轻量化方法，例如 DynamicViT、A-ViT 等。目标是降低模型参数量，并提升训练速度和/或推理速度。**仅修改 ViT 模块的参数设置不算作轻量化方法。**
4. **复杂度计算与结果分析**：对比基线模型、类别不均衡处理方法及轻量化方法的实验结果。使用 torchsummary 或其他工具计算模型参数量和 FLOPs，并结合分类表现、参数量、计算量以及训练/推理速度分析各方法的效果与代价。

## 实验要求

1. 实验由每位学生独立完成，不组队，不共享代码、训练结果或报告。
2. 必须提交：**代码 + 实验报告内容**。报告应说明 ViT 的工作流程、实验步骤和结果分析；还应呈现分类表现、参数量、FLOPs 及训练/推理速度等相关结果，并解释主要现象。
3. 评价重点：实验完整性（准确度非首要评价指标）。
