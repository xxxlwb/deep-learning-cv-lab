# 实验 2：从卷积分类到扩散生成（对应课程 5-6 讲）

课程：《深度学习与计算机视觉》
代码目录：`lab2/`

## 实验内容

1. **卷积分类**：继续针对 Fashion-MNIST 数据集，在实验 1 的数据划分和 MLP 基线基础上，训练至少含两组「卷积 + 非线性激活 + 下采样（如最大池化）」的 CNN，给出各层输出尺寸和参数量。在相同训练预算与评价流程下，比较两种模型（MLP vs CNN）的：
   - 参数量
   - 分类表现
   - 训练代价
   - 错误类型
2. **结构先验检验**：参考课堂内容，对所有样本使用同一固定像素置换，分别在原图和置换图上重新训练 MLP 与 CNN，对比检验 CNN 的性能优势是否依赖局部空间结构。（注意：置换应当同时用于训练、验证和测试。）
3. **扩散生成模型**：针对 Fashion-MNIST 数据集，自行实现并训练（简化）扩散模型，包括：
   - 前向加噪
   - 时间步条件去噪器
   - 噪声预测损失
   - 单步反向更新
   - 从纯噪声开始的完整采样

   须记录：训练样本数、通道数、扩散步数、epoch、设备和训练时间。
4. **生成结果评价**：固定训练种子、采样种子和初始噪声，展示：
   - 随机样本网格
   - 加噪与去噪过程
   - 类别覆盖
   - 训练集最近邻
   - 失败样本
   - 采样时间

   不得只挑选成功样本。
